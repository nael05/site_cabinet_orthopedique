# DSA Orthopedics

**Client Project - DSA Orthopedics**
This project is a custom-built showcase website developed for a client.
🌐 [Visit the production site: https://dsa-orthopedie.fr/](https://dsa-orthopedie.fr/)

## Description
This project is the showcase website for the practice of Damien Salhorgne, Orthotist-Podiatrist based in Jouy-le-Moutier. The site aims to present the practice, the expertise (Orthotics, Podiatry, Lymphology, Belts and Corsets, Protective Masks, Standard Equipment), as well as patient reviews, opening hours, prices, and access details, all within a modern, high-performance interface suited to the medical field.

## Tech Stack
- **HTML5**: Strong semantics, clear structure.
- **CSS3 (Vanilla)**: Styling, CSS variables, smooth animations.
- **JavaScript (Vanilla)**: Interface logic, mobile menu, animations.
- **Lucide Icons**: Icon pack integrated via CDN.

## Installation Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge).
- No backend server is required as it is a static website.

## Installation and Launch
To run the project locally, follow these steps:

1. Clone this repository to your machine.
2. Navigate to the `site_cabinet_orthopedique` folder.
3. On Windows, double-click the `run.bat` file to launch the site immediately, or simply open the `index.html` file in your browser of choice.
