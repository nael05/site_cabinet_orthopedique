# DSA Orthopédie

**Projet Client - DSA Orthopédie**
Ce projet est un site web vitrine développé sur-mesure pour un client.
🌐 [Visiter le site en production : https://dsa-orthopedie.fr/](https://dsa-orthopedie.fr/)

## Description
Ce projet est le site vitrine du cabinet de Damien Salhorgne, Orthopédiste-Orthésiste-Podologiste basé à Jouy-le-Moutier. Le site a pour but de présenter le cabinet, les expertises (Orthésie, Podologie, Lymphologie, Ceintures et Corsets, Masques de protection, Appareillages de série), ainsi que les avis patients, horaires, tarifs et modalités d'accès, le tout dans une interface moderne, performante et adaptée au domaine médical.

## Stack Technique
- **HTML5** : Sémantique forte, structure claire.
- **CSS3 (Vanilla)** : Stylisation, variables CSS, animations fluides.
- **JavaScript (Vanilla)** : Logique d'interface, menu mobile, animations.
- **Lucide Icons** : Pack d'icônes intégré via un CDN.

## Prérequis d'installation
- Un navigateur web moderne (Chrome, Firefox, Safari, Edge).
- Aucun serveur backend n'est requis car il s'agit d'un site web statique.

## Installation et Lancement
Pour lancer le projet en local, suivez ces étapes :

1. Clonez ce dépôt sur votre machine.
2. Naviguez dans le dossier `site_cabinet_orthopedique`.
3. Sous Windows, double-cliquez sur le fichier `run.bat` pour lancer le site immédiatement, ou ouvrez simplement le fichier `index.html` dans le navigateur de votre choix.
